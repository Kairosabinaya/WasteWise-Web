# PRODUCT EVOLUTION PROMPT
## WasteWise → BIMA App Transformation (Frontend Prototype)

You are a Senior Product Manager, Climate Tech Strategist, and UX Architect.

Your task is to evolve an existing application called **WasteWise** into a new platform called:

# BIMA
Bio-Energy Integrated Management with Artificial Intelligence

IMPORTANT:
This is a **FRONTEND PROTOTYPE ONLY**.

The goal is to demonstrate the **product vision**, not to build a real backend system.

---

# PROTOTYPE CONSTRAINTS

### No Backend
No database  
No authentication  
No APIs

Everything must be:

• Hardcoded  
• Static  
• Dummy data  
• Simulated interactions

---

# NO LOGIN SYSTEM

The prototype must **NOT require login**.

Instead provide a **User Role Toggle Switch**.

Example:

Viewing As:

Supplier | Gas Customer | Driver | Admin

Switching the toggle instantly updates the UI.

This allows judges to explore the system easily.

---

# CORE PRODUCT TRANSFORMATION

Original App:

WasteWise  
A gamified recycling platform.

New App:

BIMA Platform

A circular economy system that:

Collects food waste  
Processes it into biogas  
Distributes Bio-LPG  
Tracks environmental impact  
Rewards contributors

---

# USER TYPES

The system must support 4 users.

Waste Supplier  
Gas Customer  
Logistics Driver  
Admin / Control Center

All roles are accessible from the toggle.
